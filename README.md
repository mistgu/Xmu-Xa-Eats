## 📖 项目简介

「厦大翔安 · 今天吃什么」是一个**纯前端、单文件、零依赖**的移动端网页应用，内置翔安校区周边 **22 家店铺、100+ 道菜品**的真实测评数据。

打开即用，无需安装、无需后端、无需数据库——数据默认保存在浏览器 `localStorage`，也支持 CSV 一键导入导出，轻松维护属于你自己的「干饭数据库」。

> 🌰 使用场景：中午下课不知道吃啥 → 点一下「🎲 帮我决定」；晚上纠结 → 看一眼「📅 每日一签」；安利朋友 → 一键导出菜单图片发群里。

## 🚀 快速开始

### 本地使用

本项目是**单文件 HTML**，无需任何构建工具：

1. 克隆仓库：

   ```bash
   git clone <你的仓库地址>
   ```

2. 用浏览器打开 `厦大翔安·今天吃什么.html`（或 `厦大翔安·今天吃什么/厦大翔安·今天吃什么.html`）即可。

   > Windows 双击即可，手机端可通过微信「文件传输助手」发送后打开。

### 部署上线

因为是纯静态页面，可一键托管到任意静态平台：

- **Vercel / Netlify**：直接把 HTML 文件拖入部署
- **GitHub Pages**：仓库 Settings → Pages → 选择分支根目录
- **小程序 / 公众号 H5**：通过 `<web-view>` 组件嵌入网页即可

> 💡 提示：图片分享功能依赖浏览器 `navigator.share` 与 `canvas`，在微信内置浏览器中会降级为「下载 PNG」，不影响使用。

## 📖 使用说明

### 🎲 帮我决定

1. 在决策卡片中选择偏好：
   - **位置**：全部 / 校内食堂 / 校外周边
   - **预算**：不限 / 15 元内 / 15~25 元 / 25 元以上
   - **口味**：都行 / 无辣不欢 / 清淡一点 / 来点甜的
   - **用餐**：都行 / 🛵 可外卖
2. 点击「🎲 帮我决定」，程序按「招牌优先 × 人气加权」随机推荐一道菜。
3. 结果支持「🔄 换一个」「🤍 收藏」，并给出推荐理由。

### 📅 每日一签

- 以当天日期为种子，**同一天内固定推荐同一道菜**，适合跟室友「对答案」。
- 支持「🎴 换一签」（按日偏移顺延）、收藏、📤 导出分享卡片。

### 📤 数据导入导出（CSV）

在首页底部「⚙️ 数据管理」中：

- **导出 CSV**：一键导出全部店铺与菜品数据
- **导入 CSV**：按「店名」合并更新，未涉及的店铺保留
- **下载模板**：获取标准导入模板（含示例行）

CSV 字段共 18 列：

| # | 字段 | 说明 | 示例 |
| --- | --- | --- | --- |
| 1 | 店名 | 店铺名（导入合并依据） | 竞丰餐厅 |
| 2 | 位置 | `校内` / `校外` | 校内 |

## 🧬 数据结构

内置数据 `RAW_DATA` 中，每家店铺对象结构如下：

```js
{
  id: 'jingfeng',              // 唯一标识
  name: '竞丰餐厅',            // 店名
  emoji: '🍜',                 // 图标
  zone: '校内',                // 校内 | 校外
  kind: '食堂',                // 食堂/餐厅/小吃/烧烤/甜品饮品/咖啡轻食
  area: '一期学生公寓 · 共三层',
  open: '6:30–21:30',
  rating: 4.6,                 // 店铺评分
  reviewCount: 238,            // 测评人数
  tags: ['人气爆棚', '品种齐全', '性价比高'],
  intro: '翔安食堂“顶流”…',    // 简介
  delivery: false,             // 可选，是否支持外卖（默认校外=true）
  deliveryNote: '堂食 / 自提', // 可选，外卖说明
  reviews: [                   // 用户测评
    { user: '翔安干饭人', score: 5, text: '麻辣烫干拌真的yyds！' }
  ],
  dishes: [                    // 菜品列表
    {
      name: '麻辣烫干拌',
      price: 15,               // 数字价格（用于预算筛选）
      priceText: '¥12-18',     // 展示价格
      rating: 4.8,
      hot: 19,                 // 推荐人数（热度）
      rec: true,               // 是否招牌
      tags: ['面食', '辣'],    // 类别 + 口味
      desc: '翔安食堂顶流！自选食材后干拌…'
    }
  ]
}
```

## 🛠 自定义与二次开发

1. **增删店铺/菜品**：直接编辑 HTML 中的 `RAW_DATA` 数组，或通过「CSV 导入」维护（推荐）。
2. **修改分类标签**：编辑 `CATS` 数组即可增删首页分类。
3. **调整推荐权重**：`decide()` 中的 `weights` 公式决定了招牌/热度的权重，可按需修改。
4. **修改每日签文案**：编辑 `WEEK_MSG` 对象。
5. **主题配色**：`<style>` 顶部的 `:root` CSS 变量集中管理主色、辅色、阴影等。

## ❓ 常见问题

**Q：数据会丢吗？**  
A：导入/修改的数据保存在浏览器 `localStorage` 中，清除浏览器数据或换设备会丢失。建议用「导出 CSV」定期备份。

**Q：支持外卖筛选吗？**  
A：支持。默认「校外」店铺视为可外卖，可用 `delivery` / `deliveryNote` 字段单独覆盖。

**Q：能当微信小程序用吗？**  
A：可以。通过小程序 `<web-view>` 组件加载部署后的网页地址即可；分享卡片在微信内置浏览器中会自动降级为「下载 PNG」。
